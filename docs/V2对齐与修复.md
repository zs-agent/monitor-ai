## 实施约定

沿用已有FastAPI、LangGraph、GPT Researcher检索/解析适配器，不另建平行执行引擎。四层分别为数据接入、关联组织、智能体协作、Next.js交互应用。规划与整合使用可审计的确定性节点，研究与审核使用结构化模型调用；四种逻辑角色与模型实例数量分离。

快照样例明确标注为合成教学数据，离线确定性适配器用于验证状态、预算和更新链路，不计为真实模型质量实验。语义向量比较使用显式配置的向量服务，未配置时返回明确错误，不以词项分数冒充语义分数。质量指标均记录分子/分母；无标注或未测量项显示未知，失败和取消不进入正常报告对照。

## 关键修复

- 来源键只允许实际取得资料；比较/版本/风险字段严格校验，模型“支持”不能覆盖硬校验。审核缺项、重复下标和模型格式异常保留待核查。
- 未获预算、只研究未核查、原文不足均保留待核查；同问题下已获支持的结论独立保留，不被另一条不足结论连带清空。
- 反馈优先预留原排队动作额度；失败/取消计入已发生消耗。失败及保存失败不发布为正常报告，重启明确标中断。
- 异步规划/整合避免图执行线程直接修改asyncio队列；共享状态投影有界保留。SSE订阅清理、终态收尾、请求代际保护、轮询防重入已处理。
- 全量复核预览与执行共用状态准备，避免优先级计算及待核查状态不一致。
- 实验CLI失败不再误标完成，也不继续作为下一快照父状态；冻结资料逐快照传入，防止T2资料泄漏到T1。
- 人工评阅保存历史和分歧；抽屉可直接展开原文与已有核查说明。原版本缺失时不拿新版本原文冒充。
- 页面轮询响应enabled切换；批量刷新防重入；全部来源删除或仅删除部分来源时刷新洞察，避免显示过时内容。
- pytest.ini限定自有测试范围，避免误运行上游联网测试；Vitest改为ESM配置，去掉配置引起的CommonJS警告。

研究报告使用中文核查标记、来源标题、适用条件和处理概况；不再把内部问题ID及整段执行JSON直接放进报告正文，完整机器记录仍保存于状态与动作账本。

## 参数与简化界面

默认p=1+n+u+I(c<1)，研究效用4p，研究后核查效用4p+2+I(风险)。alpha、beta_verify、beta_risk、w0、wn、wu、wc和反馈轮数可由API/前端设置，均有范围/有限数值校验。消融支持drop_n/drop_u/drop_c/drop_t/equal_utility；策略adaptive/fixed/single/full；关联structured/keyword/semantic/unfiltered。

主界面突出“研究对象或问题”“想做什么”“最多研究/核查”和“开始研究”。次级入口“预览分析安排”“体验版本更新样例”。时间、来源、策略放入“更多研究选项”，权重放入“高级实验设置”，公式与备选评分按需展开。四视图名称为“资料关联 / 分析安排 / 版本对比 / 效果与评阅”。

人工校正记录对象、问题ID及理由，重算预览并传入下一次研究，不覆盖原报告。语义对照调用真实embeddings服务，未配置明确报错，不使用词项分数冒充语义分数。

AtlasDemo合成T1/T2覆盖：部署48GB FP16→16GB INT4；性能硬件/批次/精度不一致判为不可直接排名；风险补丁与绕过反馈触发补查；基础32层decoder-only事实稳定沿用且0重复动作。T2风险首轮不足，有预算时进入真实状态图回边。样例适配器不调用外部模型，标注synthetic_demo、隔离存储，示例链接不冒充联网有效。

## 使用与复现

打开/nexus?tab=research，点击“体验版本更新样例”，切换四个视图及T1/T2。启动、API字段详见research-service/README.md。敏感配置留在服务端.env，RESEARCH_RUNS_DIR可隔离数据。

离线60组矩阵，在research-service目录执行：

```text
.venv/Scripts/python.exe experiment.py --demo --mode adaptive fixed --alpha 2 4 8 --beta-verify 1 2 --ablation none drop_n drop_t drop_c equal_utility --budget 8 --output runs/demo-matrix
```

真实连续实验固定各阶段检索资料，保留真实模型调用：

```text
.venv/Scripts/python.exe experiment.py --snapshot snapshot-v1.json snapshot-v2.json --focus LangGraph --budget 2 4 --mode adaptive fixed single full --repeats 3 --evidence-fixture evidence-v1.json evidence-v2.json --output runs/experiment-matrix
```

前后端合同：python scripts/export_contracts.py生成；追加--check核对一致性。完整任务、动作及参数均留档，供应方不返回Token时记为null，宏观动作不是费用硬上限。
