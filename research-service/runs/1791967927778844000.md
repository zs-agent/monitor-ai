## LangGraph：部署条件与工程事实？
状态：reviewed；分析单元：f10e1577b8e98734；修订：1
- [supported] 官方概览页称 LangGraph 是低层级编排框架与运行时，用于构建、管理和部署长时间运行、带状态的 agent。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] 官方概览页称 LangGraph 可在同一图中混合确定性的手写步骤与 LLM 驱动的 agentic 步骤，并对 AI 在何处以及如何应用做细粒度控制。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] 官方概览页列出的核心工程能力包括：持久化执行、流式处理、human-in-the-loop、持久化、综合记忆、用 LangSmith 调试以及生产就绪部署。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] 官方概览页称 LangGraph 可以独立使用，不需要使用 LangChain 来使用 LangGraph；同时可无缝集成 LangChain 产品。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] 官方概览页给出安装命令：pip install -U langgraph 或 uv add langgraph。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] 官方概览页称 LangSmith Deployment 是面向长时间运行、有状态工作流的专用部署平台，可部署和扩展 agent，并支持跨团队发现、复用、配置和共享 agent，以及在 Studio 中可视化原型。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] 官方概览页称可先在本地用 LangGraph 原型，再通过集成的可观测性和评估移到生产；LangSmith Observability 可在同一处追踪请求、评估输出并监控部署。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] 官方概览页称 LangGraph 由 LangChain Inc 构建，其灵感来自 Pregel 和 Apache Beam，公开接口受 NetworkX 启发。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] 官方概览页称 LangGraph 面向 agent 编排，不抽象提示词或架构；若需要更高层抽象，官方建议使用 LangChain 的 agents。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] 官方概览页称使用 LangSmith 追踪需设置 LANGSMITH_TRACING=true 和 API key；并推荐设置 LangSmith Engine 以监控 trace、检测问题并提出修复。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] 官方快速入门页称构建 calculator agent 有两种 API：Graph API（以节点和边定义 agent）与 Functional API（以单个函数定义 agent）。
  来源：[https://docs.langchain.com/oss/python/langgraph/quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart)
- [supported] 官方快速入门页的示例需要设置 Claude（Anthropic）账户并获取 API key，然后在终端设置 ANTHROPIC_API_KEY 环境变量。
  来源：[https://docs.langchain.com/oss/python/langgraph/quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart)

## LangGraph：对象版本、发布与能力事实？
状态：reviewed；分析单元：f71d0505dd831e7e；修订：1
- [supported] LangGraph 官方概览将其定义为低层编排框架与运行时，用于构建、管理和部署长时间运行、有状态智能体。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] LangGraph 强调可在同一个图中混合确定性的手写步骤与 LLM 驱动的智能体步骤，以提供细粒度控制。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] LangGraph 被描述为非常低层、完全聚焦智能体编排；可以使用 LangChain 组件，但并非必须使用 LangChain。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] LangGraph 概览列出的核心能力/收益包括：持久执行、流式处理、人在环路、持久化、综合记忆、用 LangSmith 调试、生产就绪部署。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] LangGraph 由 LangChain Inc 构建；其灵感来自 Pregel 和 Apache Beam，公共接口灵感来自 NetworkX。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] LangGraph 的安装命令在文档中写作 `pip install -U langgraph` 或 `uv add langgraph`。
  来源：[https://docs.langchain.com/oss/python/langgraph/overview](https://docs.langchain.com/oss/python/langgraph/overview)
- [supported] LangGraph 快速开始提供 Graph API 示例：用 `StateGraph`、`MessagesState`、`START`、`END` 定义节点/边，用 `compile()` 编译，用 `invoke()` 调用。
  来源：[https://docs.langchain.com/oss/python/langgraph/quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart)
- [supported] LangGraph 快速开始提供 Functional API 示例：用 `@entrypoint` 定义智能体，用 `@task` 标记可执行任务；任务可在入口函数中同步或异步调用，逻辑用普通循环/条件控制流编写。
  来源：[https://docs.langchain.com/oss/python/langgraph/quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart)
- [supported] 快速开始的 Functional API 示例中，`stream_events` 支持传入 `version="v3"`。
  来源：[https://docs.langchain.com/oss/python/langgraph/quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart)
- [supported] 快速开始说明 LangGraph 状态在整个智能体执行期间持久化；使用 `Annotated[..., operator.add]` 使新消息追加到消息列表而非替换。
  来源：[https://docs.langchain.com/oss/python/langgraph/quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart)
- [supported] 快速开始的计算器示例使用 Claude 模型和 `ANTHROPIC_API_KEY`，并定义加法、乘法、除法三个工具。
  来源：[https://docs.langchain.com/oss/python/langgraph/quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart)
- [supported] 快速开始正文称示例使用 Claude Sonnet 4.5，但代码示例中的模型标识为 `claude-sonnet-4-6`；所给资料未解释这一差异。
  来源：[https://docs.langchain.com/oss/python/langgraph/quickstart](https://docs.langchain.com/oss/python/langgraph/quickstart)
